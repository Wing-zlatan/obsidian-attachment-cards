# V0.1.1 scope

Prepare the existing local Attachment Cards plugin for a GitHub release. Add file-type icons for PowerPoint (`ppt`, `pptx`) and plain text (`txt`). Preserve existing behavior and add no other product features.

Deliver a standalone repository, installation assets and source archive, English and Chinese documentation, and screenshots using neutral filenames only. Documentation must contain no real note names, research topics, local user paths or private vault content.

Acceptance: the two new icon categories render in the real Obsidian runtime; existing categories and image behavior remain intact; the release ZIP contains the three install files in the correct plugin folder; repository metadata and release version agree. Preparing the repository does not by itself publish a remote repository or submit to the community directory.
