# V0.1.2 scope

Make attachment cards easier to read within a working note, and publish version 0.1.2 to GitHub and the Obsidian Community directory.

- Reduce the height and visual weight of short-file cards. Long filenames wrap naturally and retain their version suffix and extension.
- Keep ordinary vault embed syntax and click-to-open behavior. Preserve keyboard access, the editor's surrounding whitespace, and the original note text.
- Preserve native image, note, audio and video embeds. PDF and document attachments remain cards. Do not add settings, new embed syntax, preview controls or file management.
- Correct the mistaken Word extension and use wing-zlatan as the author.
- Lead English and Chinese documentation with the writing use case and community installation. Show the same neutral note before and after enabling the plugin, including prose and an image.

Acceptance: verify real Obsidian Reading view and Live Preview, long names, a narrow pane, light/dark surfaces, file opening and keyboard activation without launching external Office apps. Verify native media and restoration on unload, unchanged note contents, release version consistency and the published directory state. Mobile emulation is recorded separately from physical-device verification.
